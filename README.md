# Leo Poly Track (Cursor app)

Play **inside Cursor** — not Safari.

Open the Cursor canvas app:

**[Leo Poly Track](/cursor/stores/user/canvases/7b40dddc-df6f-44b7-abcb-d63ec1ddc003/source.canvas.tsx)**

1. Unlock with personal key `leopoly` (backup: `leogshirley`)
2. Tap **Race**
3. Hold **GAS**, steer with **◀ ▶**, complete 3 laps

Your unlock and best time stay saved in the Cursor canvas.

## Note

The older browser/GitHub Pages build in this repo is optional. The Cursor canvas is the intended way to play on iPad via the Cursor app.
